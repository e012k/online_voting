# Online Voting System

## Project Overview

The Online Voting System is a Python-based application developed to conduct voting digitally in a secure and efficient manner.

This system allows users to:

* Register/Login
* Cast votes securely
* Prevent duplicate voting
* Count votes automatically
* Generate election results

The project uses Python, SQLite database, and OOPs concepts.
